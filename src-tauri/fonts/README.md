# Bundled document fonts

Embedded into the app (`src/export/pdf.rs`) so PDF export works offline.

- Noto Sans (Regular, Italic, SemiBold, Bold, BoldItalic) — body and headings
- Noto Emoji — emoji in pasted AI-generated Markdown

Source: Google Noto Fonts. License: SIL Open Font License 1.1 (`OFL.txt`).
